# lubinom 0.1.0

## Initial release

- Implements the Lambert-uniform binomial distribution for bounded count data.
- Provides probability mass, distribution, quantile, and random-generation functions.
- Includes threshold-based reliability measures.
- Implements maximum likelihood estimation and profile-likelihood tools.
- Provides parametric-bootstrap goodness-of-fit assessment.
- Includes comparison with binomial, beta-binomial, Kumaraswamy-binomial, and Conway-Maxwell-binomial models.
- Includes reproducibility scripts for figures, simulation studies, and data applications in `inst/paper/`.
